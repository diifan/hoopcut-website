STEP 01

Identify the original

Enter the exact source filename before the timestamp. If you rename a file, update the log too. A note that says only “third quarter” is difficult for a second editor to locate.

STEP 02

Mark readable boundaries

Use elapsed recording time and leave the setup and result visible. Start and end entries are notes, not automatic trim commands. Open the source and verify them before exporting.

STEP 03

Review a shortlist

Use the review note to mark a keeper, uncertainty or a duplicate. Move selected plays into the storyboard only after checking the source. This sheet is a location index, not the finished reel.

Read the example

The fictional first row points to eight seconds in game-01.mp4. Another editor would open that file, inspect the player before the catch and confirm that the finish is visible before selecting it.

One thing to check

Do not put the scoreboard clock in the source-time columns. A stopped game clock and a continuously recording phone quickly diverge.

Practical questions

Does this sheet cut the video?

No. It stores your notes locally in the page until you download them. Use a video editor or the clipping workflow to create actual clips.

What happens if recording was paused?

Give each new file its own name and start the elapsed source timestamp again for that file.

Are these additional Hoopcut app features?

These are free browser planning and design resources. Hoopcut’s app focuses on basketball auto clipping and Shot Tracer. The editor does not upload video or publish to a social account.
