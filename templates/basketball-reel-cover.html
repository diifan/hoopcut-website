STEP 01

Name this specific reel

Use a short title that describes the actual footage: game night, practice set or season moments. A cover should not promise a complete game when the file contains only selected clips.

STEP 02

Keep the subject recognizable

Use the correct name and number and limit supporting text. The preview is a 9:16 canvas; other display surfaces may crop it differently, so inspect the placement in the destination before posting.

STEP 03

Export and inspect

Download the PNG for a flattened graphic or SVG for later editing. Open the exported file and check long names. This tool produces a cover image, not a video or an automatic publishing action.

Read the example

The default is a fictional game-night cover. Change the supporting line to identify the session or game represented by your own selected footage.

One thing to check

Do not rely on the full canvas always being visible in a feed or profile preview. Check the actual destination crop before sharing.

Practical questions

Can I upload a photo here?

This version is a text-and-linework design. It does not upload, generate or cut out a portrait.

Is the cover linked to my reel automatically?

No. Add the exported graphic in the editing or posting workflow you use.

Are these additional Hoopcut app features?

These are free browser planning and design resources. Hoopcut’s app focuses on basketball auto clipping and Shot Tracer. The editor does not upload video or publish to a social account.
