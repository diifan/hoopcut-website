01

Keep the source and edit links separate

There are two useful references here: the original basketball video source by @cantfakethetape and the finished upload on the HoopCut channel. Label each link by its role. Calling both “the original” makes it difficult for a viewer or editor to find the recording they need later.

02

Check the picture as well as the description

The existing creator branding remains visible in this basketball edit. When reviewing a basketball video source record, note what attribution is present in the picture and what is written below the player. A description should explain the relationship between the recordings rather than imply that the uploader filmed every visible moment.

03

Use a small source record

Record the original creator handle, original URL, edited upload URL and a short description of the editing work. Keep any separate permission documentation with your working files instead of treating a public credit field as that documentation. Leave unknown event or location fields blank. Keep each reference in a separate field in your own project notes.

04

Review the note when you share again

A repost or new platform description is a chance to lose the basketball video source link accidentally. Recheck it before sharing a finished highlight elsewhere. Make sure the link still opens the intended recording and that the words around it identify the creator. Retain your source record even if a social caption needs to be shorter.
